# PRODUCT-001 - AeroDesk MVP (Fictional)

AeroDesk is a miniature mock customer management API representing cross-functional engineering work in an imaginary airport operations environment.

**Roles:** Product Manager defines requirements; Engineers implement; QA verifies; Data Science defines measurements; Department Head follows delivery risks and decisions.

**For the sharing session:** use one project context to answer different role-specific questions; demonstrate historical ADR retrieval, investigation of a live endpoint, and creation of an approved issue.

**Explicitly out of scope:** personal information, actual airport/enterprise systems, real users, production databases, payments, and unattended production operations.
